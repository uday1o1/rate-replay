# User-study evidence

This directory accepts only completed run records produced under the frozen protocol in `studies/user-comprehension`.
Run records must use the name `m6-comprehension-v1-run-NN.json` and must include all five participants, including failures.
Raw utility data, participant names, contact details, and other sensitive or identifying information are prohibited.

Create and validate a run using the commands in `studies/user-comprehension/protocol-v1.md`.
`make qualification-m6-study` fails closed when no qualifying run is present.
