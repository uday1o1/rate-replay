# Static public demo ADR

Status: Artifact generation, integrity verification, and the browser walkthrough are implemented in Milestone 6.
The external frozen user-comprehension gate remains separate from this implementation status.

The complete public walkthrough is a set of simulated immutable files generated by the released parser, billing, comparison, optimizer, verifier, and report code.
Generation begins from the locked NREL-derived profile and fixed account facts.
Every artifact is canonical JSON or a deterministic report, is named and indexed by SHA-256, and records the input manifest and calculation-contract versions.

The browser loads only logical artifact IDs listed in `artifacts/demo/allowlist.v1.json` and verifies the build-locked manifest hash, allowlist hash, and every artifact hash before use.
The allowed logical IDs cover import review, bill replay, tariff comparison, scenario inputs, unchanged reference result, heuristic result, solver result, independent verification, and redacted report.
Unknown logical IDs, mutable URLs, query-dependent payloads, and private-data references fail closed.

The original contract called for an externally signed release manifest.
A clean checkout cannot reproduce an external signature without a private release credential, and committing that credential would make the signature meaningless.
The local V1 release therefore embeds the generated manifest SHA-256 in the production browser bundle and makes no external code-signing claim.
An authorized publication may add an external signature without changing the artifact or browser-state contracts.

The demo has no shared account, cookies, server-side visitor state, uploads, mutation endpoints, authenticated requests, job creation, or anonymous API writes.
Navigation and user edits operate on browser-local copies and cannot modify the frozen evidence set.
The browser security test records all requests and rejects any method other than `GET` or any origin outside the static site.

The frozen generation entry point is `make demo-artifacts`.
It runs the locked simulated profile through the production tariff compiler, billing engine, comparison engine, optimizer, independent verifier, and redacted-report builder.
`make demo-artifacts-check` independently regenerates the release and rejects missing, extra, changed, or stale generated files.
`make browser-test` runs the pinned Playwright release with its version-matched Chromium build against a production Vite preview.
The suite exercises the complete public walkthrough, artifact corruption, request isolation, independent browser contexts, reload reset behavior, keyboard navigation, and the supported narrow viewport.
It also exercises the private upload, replay, comparison, scenario, report, deletion, and session-expiry journeys against a strict in-browser API boundary that rejects unexpected requests.
The repository makes no complete public-demo claim until the Milestone 6 browser walkthrough and its acceptance gates pass.
